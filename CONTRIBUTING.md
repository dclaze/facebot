# Contributing

Facebot is currently defining requirements. The application stack is not selected yet.

Useful early contributions include reproducible local voice benchmarks, tablet audio/camera experiments, reference projects, character concepts, and clearly scoped design proposals.

Before substantial implementation, discuss the intended change in an issue so it fits the current roadmap. Keep pull requests focused and include relevant validation. Do not claim simulated results are physical-device measurements.

Never commit credentials, household addresses, private deployment details, recordings, transcripts, identifiable visitor images, or unlicensed assets. Use synthetic fixtures. Local installation notes belong in ignored `.local/`.

Document source attribution and exact dependency/model licenses before importing third-party material. Do not assume a public repository grants permission to copy its code.
